## Преимущества

Каждый анализ данных — это снова писать заявки на SQL, вручную выгружать Excel и склеивать его, перекраивать графики в разных инструментах? А по мере роста числа таблиц и полей с непрозрачными сокращениями уже непонятно, что вообще означает каждое поле?

**DSH Data Agent возвращает аналитику к бизнес-задачам:**

- 💬 **Анализ без порога входа**: забудьте про синтаксис SQL — задавайте вопросы обычным языком (например, «сравни конверсию по каналам за последние 30 дней»). AI сам поймёт бизнес-интент, изучит структуру таблиц, напишет и выполнит запросы, шаг за шагом придёт к выводам и сформулирует понятные заключения.
- 📊 **Качественные графики и дашборды автоматически**: никаких «сухих» таблиц — по итогам анализа автоматически строятся линейные графики, столбчатые и круговые диаграммы, scatter-графики и многомерные дашборды, а одним кликом выгружается офлайн HTML-отчёт, удобный для распространения.
- 🧠 **Глубокие бизнес-инсайты**: не просто цифры — ассистент сам сравнивает динамику, находит причины аномалий, выделяет ценные сегменты клиентов и топовые категории, превращая холодные данные в готовые к применению рекомендации.
- 🏷️ **AI-управление бизнес-смыслами**: интеллектуальное сканирование базы данных с автоматической генерацией понятных бизнес-описаний таблиц и полей, с ручной верификацией и определением метрик — каждая аналитика опирается на единые и точные бизнес-критерии.
- 🔒 **Локальность, безопасность и только чтение**: нативная поддержка read-only аккаунтов и режима «только чтение»; весь анализ выполняется локально в контролируемой среде, учётные данные строго защищены.
- 🖥️ **Два интерфейса — современный Web и эффективный терминал**: работайте в наглядном веб-интерфейсе с кликабельной конфигурацией и графиками — или в быстром терминале (dsh-tui).

## Быстрый старт

### 1. Окружение

- **DeepSeek Harness `0.1.7-rc.1`** (целевая версия для `0.2.0`; все зависимости `@deepseek-ai/dsh-*` пинятся на неё)
- Доступ к целевой базе данных (локальный SQLite-файл или БД в локальной сети / облаке)

### 2. Установка

```bash
# В веб-интерфейс (рекомендуется)
dsh plugin --profile web add github:grbr2010/dsh-data-agent

# Или в терминал (dsh-tui)
dsh plugin --profile dsh-tui add github:grbr2010/dsh-data-agent
```

> Форк подключается так: `dsh plugin --profile web add github:grbr2010/dsh-data-agent`

### 3. Начинаем анализ

Текущая версия регистрирует режим данных через новый `dsh-agent-preset-registry`, не вызывая удалённый `standingKeyFor()`. Пресеты по-прежнему читаются из `$DSH_HOME/.agent-presets/<presetId>/`; реестр хоста отвечает за области видимости инструментов, переключение пустых сессий и выгрузку. Существующие кастомные пресеты и их имена не меняются. `installPreset: false` отключает установку и регистрацию пресета плагином — тогда пресет должен объявляться другим плагином хоста. Для старых версий DSH используйте соответствующие старые версии плагина.

При первом запуске после обновления автоматически обновится распознанный оригинальный пресет `data-agent` — до совместимости с обязательным в новом DSH `persona.config.prefix`, с сохранением существующего поля `text`. Кастомизированные пресеты не перезаписываются; если при старте возникает `$.prefix missing required value`, сохраните копию `$DSH_HOME/.agent-presets/data-agent/agent.cordis.yml` (по умолчанию в `~/.dsh`), пропишите в config персоны `prefix` с тем же текстом, что и `text`, и перезапуститесь.

#### Способ 1: веб-интерфейс (рекомендуется)

Запустите веб-консоль, создайте сессию и выберите **«Режим данных»**:

```bash
dsh --profile web
```

1. На странице новой сессии нажмите **«Настройки подключения»** рядом с **«Режим данных»** — либо в сессии кликните **иконку базы данных** справа сверху от поля ввода и заполните подключение в открывшемся рабочем столе (можно проверить соединение);
2. После успешного подключения задавайте аналитические вопросы обычным языком;
3. Уточняйте и копайте глубже — AI продолжает анализ в контексте диалога.

#### Способ 2: терминал (dsh-tui)

Для любителей клавиатуры:

```bash
dsh --profile dsh-tui
```

В сессии: `/preset data-agent` — переключить режим, `/database connect` — подключиться к базе, и можно спрашивать.

## Рабочий стол и отчёты

### 1. Многофункциональный рабочий стол базы данных

В веб-интерфейс встроен рабочий стол из четырёх модулей: **настройка подключений**, **обзор таблиц**, **управление данными** и **выполнение SQL** — проверяйте данные в любой момент между диалогами.

<p align="center">
  <img src="assets/tables.webp" alt="Рабочий стол базы данных" width="90%">
</p>

### 2. AI-управление данными (data governance)

Откройте «Управление данными» на рабочем столе: AI автоматически сканирует структуру таблиц и генерирует понятные бизнес-описания — на русском при `enrichmentLanguage: ru` — с возможностью подтвердить, удалить или дополнить каждый смысл и определить бизнес-метрики. Больше не нужно «выравнивать поля, спрашивая коллег».

<p align="center">
  <img src="assets/data-governance.webp" alt="AI data governance" width="90%">
</p>

### 3. Интерактивные офлайн-отчёты

Когда результату нужна визуализация, ассистент автоматически строит одиночные графики или многомерные дашборды и сохраняет автономный HTML-отчёт в `analysis-reports/` рабочей директории: метрики, динамические графики и детальные таблицы — открывается двойным кликом без сети, можно отправить коллеге.

## Поддерживаемые источники данных

- 🐬 **Реляционные СУБД**: MySQL, PostgreSQL, SQLite, Oracle, Microsoft SQL Server
- ⚡ **Аналитические хранилища / OLAP**: ClickHouse, Apache Doris, Apache Hive, Apache Impala
- 📁 **Локальные и лёгкие данные**: SQLite-файлы (работают сразу, без отдельного сервера)

## Безопасность и приватность

- 🛡️ **Строгая защита «только чтение»**: рекомендуется read-only аккаунт БД и режим «только чтение» в подключении — случайные изменения и удаления данных исключены.
- 🔑 **Изоляция учётных данных**: пароли используются только во время сессии, не попадают в открытую историю и никуда не отправляются.
- 💻 **Полностью локальное выполнение**: запросы и отчёты генерируются локально в контролируемой среде — коммерческая тайна под защитой.

## Частые вопросы

<details>
<summary><b>В: Я совсем не умею писать SQL — получится ли анализировать данные?</b></summary>
Да! DSH Data Agent создан для нетехнических бизнес-пользователей и аналитиков. Опишите задачу обычным языком — AI сам поймёт intent, найдёт нужные таблицы, напишет и выполнит корректный SQL и оформит результат в понятные графики и выводы.
</details>

<details>
<summary><b>В: Есть ли риск случайно изменить или удалить данные в продакшен-базе?</b></summary>
Нет. Рекомендуем использовать read-only аккаунт и включать режим «только чтение». В этом режиме любые опасные инструкции (UPDATE, DELETE, DROP и т.п.) строго блокируются.
</details>

<details>
<summary><b>В: Таблицы и поля у нас — сокращения на латинице/пиньине, поймёт ли AI?</b></summary>
Да. Используйте «Управление данными»: AI просканирует таблицы с учётом комментариев и контекста полей и сгенерирует бизнес-описания; вы также можете вручную добавить корпоративные термины и формулы (например, «чистая выручка = сумма заказов − возвраты») — ассистент будет применять эти подтверждённые критерии в последующих анализах.
</details>

<details>
<summary><b>В: Как поделиться отчётом с коллегами, у которых нет DSH?</b></summary>
Каждый отчёт сохраняется локально как автономный <code>.html</code>-файл в каталоге <code>analysis-reports/</code>: все стили и данные встроены, не нужны ни установка ПО, ни сеть — просто отправьте файл, он открывается в любом браузере.
</details>

<details>
<summary><b>В: Можно ли задавать уточняющие вопросы по графикам и выводам?</b></summary>
Конечно! Как с живым аналитиком: «раскладывай по регионам», «замени столбчатую на круговую», «почему в мае падение в округе X» — AI продолжит копать на основе предыдущих шагов.
</details>
